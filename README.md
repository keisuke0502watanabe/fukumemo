# フクメモ（Fukumemo）— PWA プロトタイプ

福岡大学生向けの**非公式**リンク集・時間割・課題メモ。**福岡大学非公認**。
徳島大学の「トクメモ」を参考にしたもの。開発：渡邊 啓介（理学部化学科）。

## いまできること（v0.1.0）
- **ホーム**：今日の授業、締切が近い課題、よく使うリンク
- **リンク**：FUポータル・大学メール・Microsoft 365・図書館・公式サイト
- **時間割**：月〜金（土は設定で表示）× 1〜7限。コマをタップして授業名・教室・メモを入力
- **課題**：締切付きのやることリスト（締切順、超過は赤）
- **設定**：非公認の説明、データの書き出し／読み込み／全消去、時間割の表示設定
- ホーム画面に追加すると、アプリのように開ける。オフラインでも動く（Service Worker）

## 守っていること
- 画面上部に「福岡大学非公認」を**常に表示**（消せない）
- ID・パスワードなどの認証情報は**扱わない**。自動ログインはしない
- 時間割・課題は端末内（localStorage）だけに保存。**外部へ何も送信しない**
- 大学サイトには、利用者がリンクを押したときに開くだけ。スクレイピング・定期アクセスはしない
- Service Worker はこのアプリ自身のファイルだけをキャッシュする

## 動かし方
ビルド不要。静的ファイルを配信するだけ。

```bash
cd ~/Projects/fukumemo && python3 -m http.server 8765
```

ブラウザで http://localhost:8765 を開く。スマホで試すには HTTPS で公開する必要がある（GitHub Pages など）。

### Artifact 版（共有用）
`python3 build_artifact.py` で `dist/fukumemo.html`（1 ファイルにまとめた版）を作る。
公開先：https://claude.ai/artifact/DBTubSSQeiUEgFLz3yeaH1
Artifact では Service Worker・ファイルの書き出しが使えないため、「データをコピー」で代用する。

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | 画面（5タブ・編集ダイアログ） |
| `styles.css` | 見た目（ライト／ダーク対応） |
| `data.js` | リンク集・時限の定義（**ここを直せばリンクが変わる**） |
| `app.js` | 動き（保存・描画・タブ切替） |
| `sw.js` | オフライン用キャッシュ |
| `manifest.webmanifest`, `icons/` | ホーム画面追加用 |
